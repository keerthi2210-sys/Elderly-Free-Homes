# 🏡 Elderly Free Homes Website

## 📌 Project Overview

The **Elderly Free Homes Website** is a web-based platform developed to provide information about elderly care homes, facilities, services, and activities. It aims to create awareness and help people learn more about elderly care and support.

## 🎯 Project Objectives

- Provide information about elderly care facilities.
- Display available services and activities.
- Make it easy for visitors to contact the organization.
- Provide an online donation facility.
- Create a simple and user-friendly website.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## ✨ Key Features

- **Home Page:** Introduction to the elderly care home.
- **About Us:** Information about the organization.
- **Services:** Details about the services and facilities provided.
- **Gallery:** Images and activities of the home.
- **Donation:** Online donation facility.
- **Contact Us:** Contact information and enquiry facility.
- **Staff Login:** Login facility for authorized staff.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the different pages of the website.

**Note:** If PHP and MySQL functionality is included, configure the project with a local server such as XAMPP and import the required database before using those features.
